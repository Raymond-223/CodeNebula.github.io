CodeNebula — 软件开发知识体系

一个面向专业开发者与自学者的系统性软件开发知识库。覆盖从底层原理到工程实践的完整技术栈。

章节目录

章节 核心内容
概览 软件工程全景、SDLC、技术栈选型、学习路径
前端开发 HTML5/CSS3/JavaScript/TypeScript, React/Vue/Angular, 构建工具
后端开发 Python/Node.js/Java/Go/Rust 生态, 框架对比, API 设计
数据库与存储 关系型/非关系型数据库, SQL 进阶, ORM, 缓存, 存储引擎
版本控制 Git 原理与工作流, 分支策略, 协作规范
DevOps 与部署 Docker/K8s, CI/CD 流水线, 云服务, 监控告警
软件架构 架构风格, 设计模式, 系统设计原则, 微服务
测试与质量 测试金字塔, TDD/BDD, 代码审查, 重构
安全基础 认证授权, 加密体系, Web 安全, 安全编码

目标读者

  • 初学者：想系统学习软件开发、构建完整知识体系
  • 中级开发者：需要查漏补缺、深入原理
  • 转行者：从零开始、需要清晰的学习路径

如何使用

按顺序阅读，或有针对性地选择章节。每章末尾有"下一章"链接。代码示例均为可运行的真实代码。
